# Bizarrement Curieux

This directory contains the durable production recipes for the bilingual
curious-question format. Generated media never belongs here.

- `v1/` is the immutable, human-approved Remotion direction used by the first
  five French and five English episodes.
- `v2-overlay/` is an inactive configuration shell for a future OverlayMotion
  direction. It must not replace V1 until the account identity is approved.

Start with [`v1/NEW_CONVERSATION.md`](v1/NEW_CONVERSATION.md) when resuming the
format in a new Codex conversation.

Use [`CHANNEL_SETUP.md`](CHANNEL_SETUP.md) when creating or configuring the
YouTube, TikTok, and Instagram accounts. It contains the approved names,
handles, public descriptions, bios, and privacy checklist. Private owner and
login details must remain in the password manager, never in this repository.
